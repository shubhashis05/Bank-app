# Bank Application — Java

A modular, console-based banking application built using Java to practice and apply core Java concepts through hands-on development.

The application simulates basic banking operations using Java collections such as `HashMap` and `HashSet` instead of a database. It follows a modular structure with separate packages for domain models, repositories, services, exceptions, and utilities, making the code easier to maintain and extend.

**Key Features**
- Modular architecture with separation of concerns
- Banking domain models for customers, accounts, and transactions
- In-memory data management using `HashMap` and `HashSet`
- Repository and service layers for organizing application logic
- Input validation and custom exception handling
- Console-based interaction

**Tech Stack:** Java, OOP, Collections Framework, Functional Interfaces, Exception Handling

**Note:** This project uses in-memory storage only. All application data is lost when the program terminates.
